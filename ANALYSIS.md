# Vector and Scalar Evaluation

Using the sample scores of Ada = 8, Grace = NA, Linus = 12, and Barbara = 4, both cleaning functions produce the same final scores: 16, 0, 20, and 8. In `clean_scores_vector()`, `ifelse()` processes the scores together, replacing the missing value with 0 and doubling the other scores. The next line replaces any result greater than 20 with 20, so Linus' doubled score of 24 becomes 20. In `clean_scores_scalar()`, the for loop processes each score individually. It checks whether the score is missing, replaces it with 0 if necessary, and otherwise doubles it and caps it at 20. Both functions preserve the student names and return identical results.

All operations in`clean_scores_vector()` are applied at once to the entire scores vector. Specifically, the `is.na()` function, multiplication (`*`), and `ifelse()` work simultaneously to handle missing values and double the scores. Then, `adjusted > 20` checks all values in one step, allowing `adjusted[adjusted > 20] <- 20` to cap all high scores at 20 in just one batch operation.

Keeping the vector implementation in an R program is better for its concise boilerplate and faster execution speed, as it avoids explicit element-by-element iteration. The main trade-offs are readability and memory overhead. It requires familiarity with R’s vectorization conventions to understand and maintain, while operations like `is.na()` generate temporary vectors in memory rather than modifying values in place like the scalar loop. Additionally, step-by-step interactive debugging is more challenging than in the scalar version, where each element's state can be individually inspected.
